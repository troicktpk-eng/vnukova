# Training Planner

**Автор:** Внукова Полина Андреевна

## Описание
Приложение для планирования тренировок с фильтрацией, сохранением данных в JSON и контролем версий через Git.

## Возможности
- Добавление тренировок (дата, тип, длительность).
- Фильтрация по типу и дате.
- Сохранение и загрузка данных.
- Проверка корректности ввода.

## Примеры использования
1. Запустите `main.py`.
2. Введите данные и нажмите «Добавить тренировку».
3. Используйте фильтры для поиска.
4. Сохраните данные в JSON.
5. Проверьте работу с Git.
